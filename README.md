# CampusQ — Smart University Queue Management System
Stack: PHP (PDO) + MySQL + Bootstrap 5.
## Run locally
1. XAMPP চালু করে Apache + MySQL start করো।
2. এই folder-টা `htdocs/campusq` এ রাখো।
3. phpMyAdmin-এ `schema.sql` import করো।
4. http://localhost/campusq খোলো। `inc.php`-তে DB user/password দরকার হলে বদলাও।
